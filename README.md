# Student Exam Predictor

## Описание

Консольное приложение на Python, которое обучает логистическую регрессию для предсказания успешности сдачи экзамена студентом.

## Процесс обучения

1. **Подготовка данных**

   - Кодирование категориальных признаков
   - Создание новых признаков:
     ```python
     df['Средняя_оценка'] = (df['КР1'] + df['КР2'] + df['КР3']) / 3
     df['Вариация оценки'] = df[['КР1','КР2','КР3']].max(axis=1) - df[['КР1','КР2','КР3']].min(axis=1)
     ...
     ```
   - One-hot кодирование категориальных признаков

2. **Предобработка**

   - Масштабирование признаков (StandardScaler)

3. **Обучение модели**

   - Реализация логистической регрессии с
   - Параметры:
     - learning_rate = 0.05
     - max_iter = 10000

4. **Оценка качества**
   - Accuracy: ~90%
   - ROC-AUC: 0.955

## Как запустить

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/yauhenlisay/student_exam_predictor.git
   cd student_exam_predictor
   ```

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Подготовьте свои данные:

   - В папку `/data/` поместите:
     - `student_exam_data.csv` — обучающий датасет.
     - `my_input.csv` — файл для предсказания.

4. Запустите скрипт:

   ```bash
   python exam_predictor.py --input-data ./data/my_input.csv
   ```

5. Вы увидите результат:
   - Вероятность сдачи.
   - Предсказание (сдал/не сдал).

## Формат входных данных для предсказания

Файл должен содержать следующие колонки и значения :

- Контрольная 1 (1-10)
- Контрольная 2 (1-10)
- Контрольная 3 (1-10)
- Сон накануне (Да/Нет)
- Настроение (Плохое/Нормальное/Хорошее)
- Энергетиков накануне (0/1/2-3/4+)
- Посещаемость занятий (Низкая/Средняя/Высокая)
- Время подготовки (Последний час/Последняя ночь/За несколько дней/За неделю)

Пример:
Контрольная 1,Контрольная 2,Контрольная 3,Сон накануне,Настроение,Энергетиков накануне,Посещаемость занятий,Время подготовки,
4,6,8,Да,Хорошее,4+,Высокая,Последняя ночь
